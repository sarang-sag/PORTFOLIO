## 🌟 Overview

Welcome to the personal developer portfolio website of **Sarang V**. This application showcases **4+ years of professional software engineering experience**, specializing in building enterprise software systems, scalable REST APIs, and modern frontend interfaces.

### ✨ Highlights & Design Philosophy
- **Dark-First Modern Aesthetics**: Custom dark slate UI featuring glowing cyan (`#00f2fe`) and emerald (`#10b981`) accents, glassmorphism cards, and hardware-accelerated canvas background animations.
- **State Management via Signals**: Reactive theme switching (Dark/Light modes) and active section tracking via Angular Signals & RxJS.
- **Standalone Architecture**: Clean, modular structure using Angular 18 Standalone Components (`@if`, `@for` control flow).
- **Responsive Layout**: Designed mobile-first, supporting all screen breakpoints from mobile devices to ultra-wide desktop monitors.

## 💻 Getting Started Locally

### Prerequisites
Make sure you have Node.js (v18+) and npm installed on your system.

### 1. Clone the repository
```bash
git clone https://github.com/sarang-sag/PORTFOLIO.git
cd PORTFOLIO
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start development server
```bash
npx ng serve
```
Open your browser and navigate to **`http://localhost:4200/`**. The application will automatically reload if you change any source files.

### 4. Build for Production
```bash
npx ng build
```
The build artifacts will be stored in the `dist/portfolio-app` directory.
